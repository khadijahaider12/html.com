NOORÉ — Islamic Fashion & Lifestyle Homepage
=============================================

FILES
- index.html: website structure and content
- style.css: responsive emerald-green and gold design, animations, and layout
- script.js: mobile menu, image slider, theme toggle, search demo, collection interaction, newsletter feedback

HOW TO OPEN
1. Extract noore_islamic_fashion.zip into a folder.
2. Open that folder in Visual Studio Code.
3. Open index.html and choose "Open with Live Server" (if installed), or double-click index.html.
4. Internet is needed for Google Fonts and the remote Unsplash photos.

NOTES
- This is a front-end demo. Search, bag, and collection interactions are illustrative; there is no payment, account, or product database.
- The newsletter form shows a demo confirmation only; it does not save email addresses.
- Replace the sample links and imagery with your own licensed assets before publishing.
- Islamic text and translations are provided as example content; please verify them against trusted sources before publishing.
